# 🎹 NotaRe Academy & Studio v3.0

Интерактивный курс и тренажёр беглого чтения нот с листа на фортепиано. Основан на современных психологических и фортепианных методиках обучения взрослых (система **Nota Re**, методики **Ф. Брянской**, **Ю. Фроловой**, **Е. Олёрской**, **М. Литовко**, **Н. Ушаковой**, **Paul Harris**, **Ш. Л. Ганона** и **К. Черни**).

---

## ✨ Основные возможности

### 🎓 1. Интерактивный курс (12 недель / 4 модуля)
* **Пошаговая программа**: от первичной постановки пятипальцевой позиции до независимости штрихов двух рук.
* **Автоматический зачёт нормативов**: тренажёр фиксирует серию однотипных упражнений, процент точности (≥90–94%) и скорость реакции (<500–800 мс).
* **Мгновенные пресеты**: один клик настраивает диапазон, тональность, темп метронома и специальный режим для конкретного урока.

### 🎹 2. Тренажёр-Студия (Sight-Reading Studio)
* **8 методических режимов читки**:
  1. **⚡ Рефлекс** — прямая дуга «вижу графический знак → палец жмёт клавишу», отключение внутреннего голоса.
  2. **🎵 Ритмослоги** — фонетическая система слогов (ТА, ТИ-ТИ, ТИ-РИ-ТИ-РИ, ТА-А) вместо перегружающего счёта «раз-и-два-и».
  3. **👁️ Бегунок (+1)** — динамическая шторка скрывает сыгранные ноты, принудительно выталкивая взгляд вперед.
  4. **📸 Фото-память** — кратковременная экспозиция такта (1.1–2.4 с) с последующей маской для тренировки зрительного снимка.
  5. **📐 Интервалы** — графический декодинг расстояний: асимметрия «линия–окошко» (соседний палец) против симметрии «линия–линия» (через палец).
  6. **↰ Буква «Г»** — траектория сканирования при игре двумя руками: бас на 1-ю долю ➔ скольжение взгляда вверх и вправо по мелодии.
  7. **🖐️ Вслепую** — тактильная ширма (скрывает надписи белых клавиш, выделяет островки из 2 и 3 чёрных клавиш) + режим мысленной игры **«Стол»**.
  8. **💪 Ганон & Штрихи** — секвенции для укрепления слабых 4-го и 5-го пальцев, считывание блоков по 4 ноты, независимость артикуляции (стаккато в басу + легато в мелодии).
* **Векторный панорамный нотный стан (SVG)**: скрипичный и басовый ключи, ключевые знаки тональностей, добавочные линейки, штили, флажки, дуги интервалов, векторы «Г», тактовые черты, аппликатура и текст слогов.
* **Полноразмерная виртуальная клавиатура на 3 октавы (C3–B5)** с адаптивной версткой, подсветкой звукоряда и визуализацией нажатий.

### 🧭 3. Доигровой анализ & Кварто-квинтовый круг
* **5-шаговый протокол**: чек-лист действий пианиста за 30 секунд до первого касания клавиш (Характер ➔ Знаки ➔ Размер ➔ Ключи ➔ Самый мелкий ритм).
* **Интерактивный круг тональностей**: C-dur, G-dur (1♯), F-dur (1♭), D-dur (2♯) с быстрым запуском на стане.

### 💪 4. Лаборатория Ганона и Ритма
* Готовые тренировочные паттерны: Ганон №1, Ганон №2, Этюды Черни (блоки по 4 ноты), координация штрихов.
* Библиотека ритмослогов с интерактивными аудио-примерами и метрономом.

### 📚 5. Библиотека первоисточников
* Каталог 60+ методических пособий и сборников, сгруппированных по 4 модулям курса.
* Выжимка ключевых нейрофизиологических принципов читки.

### 🔌 6. Аппаратная интеграция
* **Web Audio API**: встроенный синтезатор с гармониками, аутентичный клик метронома и вокальные превью.
* **Web MIDI API**: прямое подключение цифровых пианино и MIDI-клавиатур (авто-распознавание портов, обработка velocity).

|---|---|
| <kbd>Z</kbd> – <kbd>M</kbd> | Басовый ключ (C3 – B3) |
| <kbd>Q</kbd> – <kbd>[</kbd> | Первая и вторая октавы (C4 – F5) |
| <kbd>2</kbd>, <kbd>3</kbd>, <kbd>5</kbd>, <kbd>6</kbd>, <kbd>7</kbd>, <kbd>9</kbd>, <kbd>0</kbd>, <kbd>=</kbd> | Чёрные клавиши (диезы и бемоли) |

## Как проверить версию приложения

В шапке Nota-Re постоянно отображается версия из `package.json`
и короткий Git-коммит собранного кода, например
`v3.0.0 · abc1234 · dev`. Те же сведения видны внизу **Настроек**.
Номер версии может не меняться между исправлениями, поэтому сравнивайте
**также хеш коммита**. `dev` обозначает локальный сервер разработки,
`production` — собранную версию. Хеш отражает последний коммит,
а не незакоммиченные изменения в рабочей папке.

После `git pull origin main` перезапустите `npm run dev` и обновите
страницу. Детали автоматических и аппаратных проверок:
[Release QA](docs/RELEASE_QA.md).

## Светлая и тёмная темы

Переключатель **Светлая / Тёмная** с иконками солнца и луны постоянно
доступен в правой части верхней панели, рядом со звуком и MIDI. Тема
применяется ко всем разделам NotaRe и сохраняется после обновления страницы
в `localStorage` под отдельным ключом `notare-theme-v1`; настройки уроков
при этом не изменяются.

По умолчанию для существующего оформления используется тёмная тема.
В светлой теме сама поверхность нотного стана остаётся тёмной:
контраст нот, цветовые сигналы и визуальные учебные элементы должны
оставаться одинаковыми при оценке упражнений в обоих режимах. Также
сохраняется привычный вид белых и чёрных клавиш виртуального пианино.

## Сохранение пользовательских настроек

Nota-Re сохраняет режим тренировки, нотный диапазон, тональность, темп,
число нот, параметры Ганона, подсказки, отображение клавиатуры,
длительность фото-экспозиции, состояние звука и последний выбранный урок
в `localStorage` браузера. Настройки сохраняются сразу при изменении,
в формате с номером версии и проверкой допустимых значений. Некорректные
поля сбрасываются к значениям по умолчанию, не ломая приложение.

При обновлении страницы **не** возобновляются автоматически проигрывание,
метроном, экзамен или зачётная серия. Текущие попытки, скорость реакции,
активная нота и MIDI-подключения являются данными текущей сессии.
Законченные уроки сохраняются отдельно и продолжают отображаться после
перезагрузки. Выбор OSMD/классического нотного стана и SoundFont хранится
в уже существующих настройках браузера.

В **Настройки тренажёра → Сбросить настройки** можно вернуть параметры
тренажёра к исходным. Сброс запрашивает подтверждение и **не удаляет
пройденные уроки**. Отдельные кнопки управления статистикой и прогрессом
курса продолжают выполнять только свои собственные действия.
Удаление данных сайта в браузере удаляет и локальные настройки.

## Экспорт нот и тестирование

В разделе **Тренажёр-Студия** кнопка **MusicXML** экспортирует текущее упражнение в файл `.musicxml`. Его можно открыть в совместимом нотном редакторе. Экспорт сохраняет высоты, длительности, ключевые знаки и два нотоносца, а отсутствующие партии заполняет паузами.

На данном этапе это **подготовительный слой для перехода на OpenSheetMusicDisplay**. Экспорт не означает поддержку одновременных партий двух рук: исходный генератор всё ещё создаёт последовательность отдельных нот.

```bash
npm ci
npm test        # Node.js 22+ (MusicXML unit tests)
npm run build  # Проверка TypeScript и production-сборки
```

## GitHub Pages

Публичная версия (после включения Pages): **https://shafranek-js.github.io/Nota-Re/**.

В репозитории откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Workflow [Deploy GitHub Pages](.github/workflows/pages.yml) автоматически запускается
**только после успешного `OSMD browser smoke` для push в `main`**.
Он собирает именно проверенный коммит с базовым URL `/Nota-Re/`, повторно
выполняет unit-тесты, проверяет готовность статических файлов, включённого
SoundFont (все части SF3) и AudioWorklet, затем развёртывает каталог `dist`.
Если Pages ещё не включён, первый запуск может потребовать настройки Source,
после чего неуспешный workflow можно перезапустить из GitHub Actions.

Локальная разработка и другие хостинги по умолчанию используют базовый путь `/`.
Для самостоятельной проверки сборки GitHub Pages:

```bash
npm ci
NOTARE_PUBLIC_BASE=/Nota-Re/ npm run build
NOTARE_PUBLIC_BASE=/Nota-Re/ node scripts/verify-pages-build.mjs
```

Для Windows PowerShell установите переменную окружения через
`$env:NOTARE_PUBLIC_BASE='/Nota-Re/'` перед командами сборки и проверки.
